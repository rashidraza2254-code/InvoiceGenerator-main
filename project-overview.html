Application Features

🔐

Authentication

JWT-based login, bcrypt passwords, role-based access control — Admin vs Cashier, enforced server-side.

🛒

POS Interface

Tabbed menu by category, search, cart with qty +/−, live total calculation with tax, service charge, and discounts.

💳

Split Payments

Multi-payment per bill — Cash, Card, UPI, or combinations. Sum validated against total ±0.01.

🧾

Receipts & PDF

Printable on-screen receipt and PDF download via jsPDF. Includes payment breakdown and VOID stamp.

📊

Analytics Dashboard

Daily revenue area chart, top items by revenue, payment mode donut, KPI cards — powered by Recharts.

🚫

Void & Audit Trail

Admin void with mandatory reason. Append-only audit log. Voided bills excluded from stats and analytics.

📋

Bill History

Date-range filter, payment-mode filter, CSV export. Daily and lifetime summary stats.

👥

User Management

Admin creates and deletes cashier or admin accounts. Self-delete blocked server-side.

GitOps Principle

CI never runs kubectl against the cluster. Git is the single source of truth. ArgoCD enforces cluster state from k8s/overlays/production/. Any manual kubectl change is automatically reverted.

CI/CD Pipeline

Triggers on push to main (paths excluding k8s/overlays/** to prevent infinite loops).

1

Test

pytest runs the full backend test suite (83 tests). Pipeline fails fast here — no image is built if tests fail.

pytest backend/tests/ -v --tb=short --junitxml=test-results.xml
2

Build & Push

Builds backend and frontend Docker images. Pushes to Azure Container Registry tagged with the short Git SHA. Layer caching via ACR cache manifests keeps builds fast.

# Tag example: invoicegenacr.azurecr.io/backend:a1b2c3d4
docker build → push to ACR (SHA tag + latest)
3

GitOps Update (replaces kubectl deploy)

Uses Kustomize to update image tags in the production overlay, then commits back to Git. ArgoCD detects the commit and syncs the cluster automatically. No cluster credentials in CI.

cd k8s/overlays/production
kustomize edit set image \
  invoicegenacr.azurecr.io/backend=...:SHA \
  invoicegenacr.azurecr.io/frontend=...:SHA
git commit -m "ci: deploy SHA [skip ci]"
git push origin main
4

Terraform (manual trigger only)

Provisions or updates Azure infrastructure — AKS cluster, ACR, Log Analytics, RBAC role assignments. Runs only via workflow_dispatch to prevent accidental infra changes on every push.

terraform init
terraform plan  -out=tfplan
terraform apply -auto-approve tfplan

Full Cloud Deployment

Prerequisites: az CLI logged in, terraform ≥ 1.6, kubectl, helm ≥ 3, docker

Bootstrap Azure — one-time setup

Creates Terraform remote state storage in Azure Blob and sets up OIDC federated credentials for GitHub Actions (no stored passwords).

nano scripts/bootstrap-azure.sh   # set your GitHub org/repo
bash scripts/bootstrap-azure.sh

Add the 3 output values as GitHub repository secrets:
AZURE_CLIENT_ID   AZURE_TENANT_ID   AZURE_SUBSCRIPTION_ID

Provision Azure Infrastructure with Terraform

Creates the Resource Group, AKS cluster, ACR, Log Analytics workspace, and grants AKS the AcrPull role.

cd terraform
terraform init
terraform plan
terraform apply

Connect kubectl to AKS

az aks get-credentials \
  --resource-group invoicegen-rg \
  --name invoicegen-aks

Install ArgoCD (GitOps)

Installs ArgoCD on AKS, registers the Application watching k8s/overlays/production/, and prints the UI URL and initial admin password.

nano argocd/install-argocd.sh   # set your GitHub repo URL
bash argocd/install-argocd.sh

Install Prometheus + Grafana

bash monitoring/install-monitoring.sh

Grafana LoadBalancer IP is printed at the end. Default credentials: admin / admin — change immediately.

Deploy — just push to main

GitHub Actions runs the full pipeline. ArgoCD syncs the cluster within ~3 minutes of the manifest commit.

git push origin main
