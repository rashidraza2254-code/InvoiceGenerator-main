💼 SaaS vs On-Premise

Option A — SaaS (Cloud)

You host, restaurants subscribe monthly
₹999 – ₹2,999 / month per restaurant

Pros

  • Recurring revenue
  • Push updates once
  • Low entry barrier
  • You control everything

Cons

  • Needs multi-tenancy
  • Data privacy concerns
  • Internet required

Option B — On-Premise Install

Install on restaurant's own server / PC
₹15,000 – ₹50,000 one-time + ₹500/month AMC

Pros

  • Works offline
  • Data stays local
  • Big one-time payment
  • No internet dependency

Cons

  • No recurring revenue
  • Manual updates
  • Hard to support remotely
  • Slow to scale

⭐ Recommendation: Start SaaS, offer On-Premise as Premium

SaaS gives you recurring monthly revenue and is far easier to scale. The codebase is almost ready — the only missing piece is multi-tenancy. Add a restaurant_id field to every record and you are 80% there. Offer on-premise as a high-ticket option for large or luxury restaurants who insist on owning their data.

🚨 Critical Gap — Multi-Tenancy

Current Problem

Right now server.py has one global settings document (_id: "default"), one shared user pool, one shared menu, and one shared customer list. If Restaurant A and Restaurant B both use your SaaS, their data will mix together.

Fix needed: Add a restaurant_id field to every MongoDB collection (bills, menu_items, customers, tables, branches, promos) and create a separate restaurants collection for tenant management. Every API query must filter by the logged-in user's restaurant_id. This is 1–2 weeks of dev work and unlocks the entire SaaS model.

🔴 Must-Have Features (for restaurant adoption)
Feature Why Restaurants Need It Priority
Thermal Printer / KOT Printing 90% of restaurants use thermal POS printers. Without this, cashiers cannot print bills at the counter. Critical
PDF Invoice Download Customers always ask for a soft copy. Currently only WhatsApp text is sent — no downloadable PDF. Critical
GST-Compliant Invoice Format Indian restaurants are legally required to show GSTIN, HSN codes, and proper GST breakdowns on bills. Critical
Offline Mode (PWA) Internet goes down = billing stops. Restaurants refuse software that fails when Wi-Fi is unstable. Critical
Daily Closing / Z-Report End-of-day cashier summary showing cash collected, card collected, total bills — mandatory in most restaurants. Critical
